IBM Plex Sans - bundled panel font
==================================

Family:      IBM Plex Sans
Weights:     400 (Regular), 500 (Medium), 600 (SemiBold)
Subset:      Latin only
Format:      WOFF2
Files:       ibm-plex-sans-latin-400-normal.woff2
             ibm-plex-sans-latin-500-normal.woff2
             ibm-plex-sans-latin-600-normal.woff2

Provenance
----------
Upstream project: IBM Plex (https://github.com/IBM/plex)
Redistribution:   @fontsource/ibm-plex-sans@5.2.5, which repackages the
                  Google Fonts build (https://github.com/google/fonts) of
                  IBM Plex Sans v21 into per-subset WOFF2 files.
Retrieved from:   https://cdn.jsdelivr.net/npm/@fontsource/ibm-plex-sans@5.2.5/files/
